# Glimlink 0.1.0-alpha.1

First deployable Linux x86_64 Alpha of the headless Runtime and terminal operator.
Use [the deployment guide](../deployment.md). The optional Tauri desktop remains
a separate source build.

The deployable path covers saved subscription login, one on-demand native engine,
shared persona/memory, bounded autonomous reading and semantic platform/media
tools. Bilibili, Tieba, GitHub and read-only X are in the trial scope. New public
interactions still need their own real-account acceptance when not already
listed in [validation](../validation.md). The starter profile is read-only.

Deployment blockers fixed for this release:

- Native engine discovery works beside the installed executable or via explicit
  absolute-path environment overrides, without the development `/cache` layout.
- Version/doctor inspection does not start login or read native credential files.
- User-local installation preserves existing configuration and private state.
- Pinned, checksum-verified upstream engine installers support local archives and
  use destination disk space rather than a small RAM-backed `/tmp`.
- A user-service template provides a 512 MiB hard memory cap and serial engines;
  source, notice texts, checksums and startup templates accompany the binaries.

Known Alpha limitations: QQ live login remains blocked; Weixin is paused. Login
management or a standalone MCP server on the same state requires stopping the
daemon. A prior model/video/ASR workload reached
the 512 MiB limit, so this is not a universal memory-fit guarantee. Interrupted
or failed autonomous activities require explicit inspection/resume. This release
does not claim unattended production readiness or fresh-login acceptance on every
provider/IP environment.
Native CLI transcript/cache retention is also not yet covered by Runtime cleanup.

Release checks: 612 distinct account-free tests passed (five opt-in tests were
ignored), with clean vendored-source compilation and documentation checks. Two
older assertions were updated to the explicit preview/detail contract and
portable engine discovery. Fresh Debian 12 and Debian 13 containers, without
network, host state, Python, Node or a Rust toolchain, passed install, version,
doctor, local operator capabilities, persona/profile/activity initialization,
private modes, installed notices and configuration-preserving reinstall checks.
The two pinned engine installers produced the same native hashes previously used
in real acceptance. These checks do not replace provider account validation on
your VPS.

Project-authored code remains MIT. Existing adapted/mixed and third-party files
retain their notices and licenses; this release makes no new MIT claim over them.
The Runtime links AGPL/GPL components, so the combined executable is not MIT-only.
The source asset includes the locked registry dependency sources and the modified
path dependencies needed to build it offline. Native engines, signers, downloaded
models, accounts, reports, unreviewed artwork and quarantined reference vectors
are absent from the distributed assets. Mixed-source inventory labels remain
explicit for any future ownership split/relicensing; the path-only audit still
does not act as legal clearance. See [source ownership](../OPEN_SOURCE.md).
