# Provider identification assets

The public repository ships text marks, not the image files listed below.
The files are excluded from Git and the source-release manifest; local copies
and this provenance record are retained while redistribution terms are reviewed.

These are **third-party assets, not our MIT artwork**. Names, marks, copyrights
and trademark rights remain with each provider. Our original app icon, frontend
code and layout remain separate.

The [machine-readable manifest](sources.json) records exact download URLs,
official source pages, owners, SHA-256 hashes and usage references. Asset bytes
are unchanged; no recoloring, cropping, animation or filters are added by our UI.
They appear only beside the named integration, at secondary scale, with preserved
aspect ratios and spacing. An unavailable image falls back to a text initial.
There are no remote icon requests at application startup.

GitHub provides its [logo files and integration usage guidance](https://brand.github.com/foundations/logo).
Antigravity provides [press assets](https://antigravity.google/press).
OpenAI's [brand terms](https://openai.com/brand/) cover provider-identification
uses and preserve its ownership. Tencent's [statement](https://www.tencent.com/legal-statement/)
reserves the QQ/Weixin marks. A public favicon or a download button alone is not
a blanket open-source license.

Including a file in a source-path audit is not a legal clearance. Public release
review must retain the owners and applicable conditions, establish rights for
the intended distribution or omit/replace the affected asset. This repository
does not redistribute these image files in its public source or Alpha assets.
